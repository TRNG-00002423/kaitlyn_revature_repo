# Task breakdown for US-201

**User story:** As a clinic admin, I want role-based access so only authorized staff see PHI.

**Tasks:**
- **(dev)** Implement user login UX.
- **(spike)** As a team, learn and document a clear and concrete understanding of hospital roles.
- **(docs)** Document a definition of authorized staff and what information they should and shouldn't be able to access.
- **(test)** As an authorized hospital administrator, I should be able to access all the data defined in the documentation.
- **(test)** As an unauthorized party, I should not be able to access sensitive medical information.
