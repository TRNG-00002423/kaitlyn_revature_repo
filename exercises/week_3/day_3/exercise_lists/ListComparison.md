# ArrayList vs LinkedList — your analysis

In this to-do list application, `LinkedList` might have been preferable if the user interacted with their list by checking off the first or the last item from the list (i.e. a queue) rather than indexing their tasks. This is because `get(i)` is $O(N)$ on a `LinkedList` and $O(1)$ on an `ArrayList`, making `LinkedList`s better when calling `get(i)` isn't needed. If the order of the items on the to-do list was important (e.g. a recipe), then a `LinkedList` could be used. The benefit to using a `LinkedList` instead of an `ArrayList` is that they use less space in memory and adding an element to a `LinkedList` is always $O(1)$, while adding an element to an `ArrayList` is $O(N)$ if that element is added to the middle of the list rather than the beginning or the end. However, an `ArrayList` is a better way to implement a to-do list when getting elements by their index is required.
